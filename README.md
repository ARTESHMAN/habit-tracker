Momentum is a highly customizable, client-side web application designed to gamify your life. Whether you are a student, developer, researcher, or fitness enthusiast, Momentum acts as your Personal RPG Operating System. 

It tracks your habits, manages your focus timer, builds your custom skill trees, and fights "bosses" based on your real-life progress.

**No backend. No databases. No sign-ups.** All your data is stored securely in your browser's `localStorage`.

---

## ✨ Features

- **🎮 RPG Progression System:** Earn XP, level up, and maintain streaks by completing daily quests.
- **🛠️ 100% Customizable:** Create your own categories, skill trees, roadmap, and custom boss fights directly from the UI.
- **⏱️ Built-in Focus Timer:** Pomodoro-style focus sessions that automatically reward you with XP and log your study hours.
- **📊 Dynamic Analytics:** Generate visual heatmaps, weekly progress charts, and stats using pure CSS (No external charting libraries).
- **🎨 Theming:** Adjust the app's name, primary/secondary neon colors, and border radius to fit your style.
- **🔒 Privacy First:** Your data never leaves your device. Features built-in one-click JSON Import/Export for manual backups.

---

## 🚀 Quick Start (Zero Setup)

Since Momentum is entirely client-side, you can host your own instance in less than 2 minutes using GitHub Pages:

1. **Fork** this repository.
2. Go to your repository **Settings** > **Pages**.
3. Under *Build and deployment*, set the Source to **Deploy from a branch** and choose the `main` branch.
4. Click **Save**.
5. Wait 1-2 minutes and open your generated GitHub Pages URL!

*Alternatively, simply download the source code and open `index.html` in any modern web browser.*

---

## 📂 Project Structure

A clean, dependency-free architecture:
- `index.html` - The main application structure and UI layout.
- `style.css` - Custom styling, CSS grid heatmaps, and glassmorphism effects.
- `script.js` - Core logic, state management, UI rendering, and localStorage handling.

*No npm, no Node.js, no build steps required.*
